# Tiếng Việt cho Visual Studio Code

Gói ngôn ngữ cá nhân dựa trên DMCTN Vietnamese Language Pack, được cập nhật catalog theo Visual Studio Code 1.146.0.

## Phạm vi cập nhật

- Đối chiếu đủ 32.108 khóa giao diện lõi của VS Code 1.146.0.
- Đồng bộ các chuỗi `package.nls.json` của extension tích hợp, bao gồm Copilot Chat, Dotenv, Mermaid Markdown và bộ icon hiện đại.
- Giữ nguyên bản dịch đã có; các chuỗi còn thiếu được dịch tự động và cần được hiệu đính thêm trong quá trình sử dụng.
- Một số tên giao thức, thuật ngữ lập trình, nhãn thương hiệu và chuỗi chỉ chứa placeholder có thể vẫn giữ tiếng Anh.

## Cài đặt để chạy thử

1. Mở VS Code.
2. Mở Command Palette bằng `Ctrl+Shift+P`.
3. Chọn `Extensions: Install from VSIX...` và mở `hungthinhpack-1.1.1.vsix`.
4. Chạy `Configure Display Language`.
5. Chọn `Tiếng Việt` rồi khởi động lại VS Code.

Nếu phát hiện câu dịch sai hoặc còn tiếng Anh, ghi lại vị trí giao diện và câu đang hiển thị để hiệu đính ở bản kế tiếp.

## Nguồn và giấy phép

Bản riêng này kế thừa cấu trúc và các bản dịch có sẵn từ DMCTN Vietnamese Language Pack của Bùi Văn Tĩnh. Giữ lại giấy phép MIT và ghi nhận tác giả gốc.
